## Variant: Split by actor

### Design stance
Ownership is the primary navigation model.

### Key choices
- Layout: three lanes for owner, loop, and external work.
- Typography: card-based and highly scannable.
- Color: each actor has a stable semantic color.
- Interaction: filter to actionable work and expand cards for rationale.

### Trade-offs
- Strong at: preventing automatic and manual work from being confused.
- Weak at: showing long dependency chains.

### Best for
- Mixed human-agent operations where responsibility matters more than sequence.
