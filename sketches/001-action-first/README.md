## Variant: Action-first

### Design stance
Show the single highest-value owner action before any dependency detail.

### Key choices
- Layout: one owner-action hero with automatic and later work below.
- Typography: compact operational hierarchy.
- Color: amber means human judgment; green means automatic readiness.
- Interaction: open the decision or request an immediate automatic run.

### Trade-offs
- Strong at: answering “what must I do now?” in one glance.
- Weak at: exploring the full dependency graph.

### Best for
- An owner who checks the queue briefly and wants one clear next action.
